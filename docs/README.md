# Documentation

The public documentation has one maintained entry point for each concern:

| Document | Purpose |
|---|---|
| [`workflow_design.md`](workflow_design.md) | Current architecture, responsibility boundaries and workflow lifecycles |
| [`evaluation.md`](evaluation.md) | Metrics, conditions, final-state contracts and statistical protocol |
| [`results.md`](results.md) | Current authoritative results, limitations and reproduction commands |
| [`human_evaluation_v5_protocol.md`](human_evaluation_v5_protocol.md) | Frozen single-reviewer study protocol |
| [`external_workbench_protocol.md`](external_workbench_protocol.md) | Frozen external-method comparison protocol |
| [`google_calendar_setup.md`](google_calendar_setup.md) | Optional Google Calendar integration |

The two versioned protocol documents are retained because their hashes are part of the
reproducibility record. Superseded planning notes and duplicate workflow specifications are
not kept in the public tree.
